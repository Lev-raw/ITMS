# Intelligent Traffic Management System

An AI-based traffic monitoring system that uses computer vision to detect and track vehicles from traffic video footage.

The system estimates traffic congestion and recommends green signal timing based on the number of visible vehicles.

## Features

- Vehicle detection using pretrained YOLO
- Detection of cars, motorcycles, buses, and trucks
- Vehicle tracking using YOLO tracking IDs
- Visible vehicle counting
- Unique tracking ID counting
- Congestion estimation
- Rule-based adaptive traffic signal timing
- Real-time OpenCV dashboard
- FPS and processed frame display
- CSV traffic data logging

## Congestion Logic

The current MVP uses simple rule-based thresholds:

| Visible Vehicles | Congestion Level | Recommended Green Time |
|------------------|------------------|-------------------------|
| 0–3              | Low              | 20 seconds              |
| 4–7              | Medium           | 40 seconds              |
| 8 or more        | High             | 60 seconds              |

These values are configurable and depend on the camera angle and traffic video.

From the project root, run:

## Important Limitation

The current system counts vehicles visible in each frame. The unique vehicle count is based on tracking IDs generated by the tracking model.

A tracking ID may change if the vehicle is temporarily lost or re-detected. Therefore, the unique tracking ID count should not be treated as a perfect real-world vehicle count.

The signal timing is a rule-based simulation. It does not directly control real traffic signals.
